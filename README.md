# 2027 秋招 · 岗位追踪工作台

> 一个辅助秋招的工作台，目前包括**信息搜集**、**我的投递**和**秋招仪表盘** 3 个功能；**网申填写**、**岗位匹配**正在开发中。

---

## 一、简介

这是一份**纯前端、零后端**的个人秋招管理工具，目标是把「海量公司的岗位开放情况」和「自己的投递进度」集中到一处，告别散落在浏览器书签、备忘录和 Excel 里的混乱。

- 所有数据都在你的浏览器本地（localStorage），不上传任何服务器，隐私可控。
- 岗位种子数据来自公开信息，集中在 `data/positions.js`，可按需补充。
- 界面清爽、支持搜索 / 筛选 / 状态流转，并配有实时统计的仪表盘。

适合正在准备校招、需要系统化管理「投了哪些、卡在哪一环、还剩多少坑位」的同学。

## 二、功能介绍

### ① 信息搜集（已上线）
公司级岗位清单，一张表管全部。
- **9 个字段**：信息更新时间、公司名称、公司类型（民企 / 外企 / 央国企）、公司行业、工作地点、岗位类别、截止时间、投递链接、投递状态。
- **状态管理**：每行可在 `未浏览 / 已投递 / 不投递` 间切换；未浏览置顶淡灰、已投递居中淡绿、不投递沉底淡红。
- **搜索与筛选**：支持按公司 / 城市 / 行业 / 岗位类别关键词搜索，并按类型、类别、状态多维筛选。
- **同步官方开放库**：一键把新增开放的 2027 届秋招公司同步进列表（按稳定 id 去重，**不会覆盖你已填的投递状态**）。
- **新增 / 编辑 / 删除**公司，或批量**导入 / 导出** JSON 备份。
- 一键「重置为未浏览」，方便重新过一遍清单。

### ② 我的投递（已上线）
看板式的投递进度管理，把状态为「已投递」的公司自动转入。
- **6 列看板**：投递简历 → 测评 → 笔试/AI面试 → 面试 → 拒绝 → 获得 offer。
- **阶段流转**：每张卡片可「进入下一流程」「被拒绝」；面试阶段区分 1 面 / 2 面 / 3 面，3 面后再下一流程即进入 offer。
- **联动信息搜集**：在信息搜集里把公司改为「已投递」并填写具体岗位名（**岗位名不可为空**），该公司立即出现在 `投递简历` 列。

### ③ 秋招仪表盘（已上线）
一屏看清你的秋招全景。
- **KPI 卡片**：收录公司数、已投递数、获得 offer 数等关键指标（带数字滚动动画）。
- **公司状态分布**：甜甜圈图展示未浏览 / 已投递 / 不投递占比。
- **公司类型分布**：纵向柱状图展示民企 / 外企 / 央国企占比。
- **投递进度**：横向条形图展示看板 6 个阶段的分布情况。

### ④ 网申填写（开发中 🚧）
> 后续可把简历信息自动带入各公司网申表单，减少重复填写。

### ⑤ 岗位匹配（开发中 🚧）
> 后续可基于你的求职意向与简历，智能匹配高契合度的公司。

## 三、如何使用

### 方式一：直接打开（最简单）
双击 `index.html` 用浏览器打开即可使用。

> ⚠️ 注意：部分浏览器在 `file://` 协议下会限制 localStorage，导致数据无法保存。如果遇到「刷新后数据丢失」，请改用下面的本地服务器方式。

### 方式二：本地静态服务器（推荐，数据可持久化）
在仓库根目录起一个本地服务器，再用浏览器访问：

```bash
# Python（任选一条）
python -m http.server 8000
# 或 Node
npx serve .
```

然后浏览器打开 `http://localhost:8000`。

### 日常操作速览
| 想做的事 | 怎么做 |
| --- | --- |
| 加一家新公司 | 信息搜集页 → 「+ 新增公司」 |
| 标记已投递 | 信息搜集页状态改成「已投递」并填岗位名 → 自动进我的投递 |
| 推进投递流程 | 我的投递页 → 点卡片 → 「下一流程」/「被拒绝」 |
| 看整体进度 | 秋招仪表盘页 |
| 备份 / 迁移 | 左侧菜单「导出」「导入」JSON |
| 同步新开放岗位 | 信息搜集页「同步官方开放库」 |

## 五、技术栈与目录结构

**技术栈**：原生 HTML / CSS / JavaScript，无框架、无构建步骤、无后端；数据持久化使用浏览器 localStorage；字体使用 Sora / Manrope。

```
.
├── index.html              # 页面骨架与 5 个页面
├── styles.css              # 全站样式（含暗色/浅色适配）
├── app.js                  # 核心逻辑：数据模型、渲染、看板流转、仪表盘
├── data/
│   ├── positions.js        # 公司级岗位种子数据（window.QIUZHAO_SEED）
│   └── scrape/             # 真实大厂岗位抓取原始 JSON
├── aggregate_companies.js  # 将岗位级数据聚合为公司级
├── consolidate.js          # 合并抓取数据进种子库
├── build_seed.js           # 构建种子数据脚本
└── README.md               # 本文件
```
